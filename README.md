# Tanmoy's Private Care

> A modern, secure, and full-stack educational platform designed to manage students, notices, exam results, and administrative controls with a sleek, futuristic UI.

---

##  Key Features

- **Role-Based Access Control (RBAC):** Secure routing and dashboard access separating administrators and regular students.
- **Advanced Admin Dashboard:**
  - **Result Management:** Publish and calculate total marks (CQ & MCQ) dynamically via student roll numbers.
  - **Notice Board:** Broadcast instant announcements and manage notices.
  - **Student & Admin Directory:** Filter students by class (Class 11 & Class 12), search by name, roll, or college, block/unblock users, delete accounts, and promote/demote user roles seamlessly.
- **Robust Security & Connection Pooling:** Optimized MongoDB connection management and secure backend middleware configuration.
- **Modern UI/UX:** Built with a dark mode aesthetic, smooth transitions, and responsive layout designs.
- **Session Management:** Integrated authentication and secure cookie handling.

---

##  Tech Stack

### Frontend
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Client Auth:** Better Auth Client

### Backend
- **Runtime:** Node.js, Express.js
- **Database:** MongoDB (Native Driver with Connection Caching)
- **Security & Middleware:** CORS, dotenv, optimized error handling
